# 踩坑清单

按出现频率排序，每条都对应一次真实排查。

## 环境与端口

| 问题 | 现象 | 解决 |
|---|---|---|
| QUATERNION 端口掉绑定 | `qw = 1.00` 恒定 | Apply 后重新连线并验证 |
| VEC3 端口掉绑定 | 输出恒 0 | 同上；必要时拆成三个 REAL |
| `yaw_target` 掉绑定 | 面板数值正常但电机不动 | 把输出端口移到 `define()` 最后一行 |
| 两个端口同名 | 一个覆盖另一个 | 修改后统一命名 |
| 端口名不匹配 | 链接板的 `traj_high` 接不到母板 | 两端名字必须完全一致 |

## 单位与数学

| 问题 | 现象 | 解决 |
|---|---|---|
| 度/弧度混用 | 仰角 601°、pitch_target = −6 rad | 求解函数返回度，必须 `* D2R` |
| `wrapPi` 用在指令上 | 转半圈炮塔绕整圈 | 只对**增量**用 `wrapPi` |
| 用 `atan2(fx,fz)` 求方位 | 炮管抬高时方位跳变 | 改用四元数偏航 |
| 前向轴选错 | 方位差 90° 或 180° | 试 4 个轴，用已知朝向验证 |

## 控制环

| 问题 | 现象 | 解决 |
|---|---|---|
| 正反馈 | 炮塔自转、越转越快 | 翻符号，一次只改一个 |
| 累积式反演 | 指令一路顶到限位 | 改用相对增量 + 步长限制 |
| 死区过小 | 持续小幅抽搐 | 死区 > 机械回差 |
| 死区过大 | 静止时偏差大 | 折中，或做机械预紧 |
| 用实测角做基准累加 | 追着自己跑 | 基准改用**自己的指令** |

## 弹道

| 问题 | 现象 | 解决 |
|---|---|---|
| `V0` 用错弹种 | 仰角恒为端点值 | CBC 大炮 `V0 = 2×装药`，CBCMW 中口径另算 |
| `k`（炮管长度）未计 | 射程系统性偏 3–5% | 按实际方块数填 |
| 求解区间端点当解 | 恒 60° | 检查 `solvePitch` 是否只返回了边界 |
| 超程 | 无解返回 nil | 提示玩家加装药或靠近 |

## 弹药与模组干扰

| 问题 | 现象 | 解决 |
|---|---|---|
| CBCAT 改写弹道 | 拟合怎么都不对 | `cbc_at-server.toml` 里 `disablePhysicRework = true` |
| 殉爆 | 弹药架被击中连锁爆炸 | `cbcmsmwcompat-server.toml` 的 `cook_off` 段 |
| 炸膛 | 炮管随机爆炸 | `createbigcannons-server.toml` 的 `disableAllCannonFailure = true` |

## 性能

| 问题 | 现象 | 解决 |
|---|---|---|
| 逐 tick 模拟过密 | `exceeded the wall-clock limit (250 ms)` | 降迭代上限、加距离滞环 |
| 每帧重算 | 同上 | `if |R − elevR| > 5 then` 才重算 |
| 分配爆炸 | `exceeded the allocated-memory limit` | 避免每帧建表，复用局部变量 |

## 编排类

| 问题 | 现象 | 解决 |
|---|---|---|
| 中文注释 | `unexpected symbol` | 注释只用 ASCII |
| 粘贴丢行 | `'end' expected (to close 'if' at line N)` | 重新整段粘贴，核对 end 数量 |
| 双冒号 | `')' expected` | `Vector3d:new` 不是 `::` |
