# 方位控制：闭环、传动比、防震荡

## 1. 方位必须用相对角

```
rel = azimuth(炮塔) − azimuth(车体)
```

只用车体方位做基准，炮塔转动的部分由实测补回。否则车体一转，目标方位就错。

## 2. 传动比必须先测

方法（manual 模式）：

1. `cmd = 0`，读 `turret_deg` → T0
2. `cmd = 0.5`（28.65°），读 `turret_deg` → T1
3. `K = 28.65 / |T1 − T0|`

| `|T1−T0|` | K | 说明 |
|---|---|---|
| 28.65° | 1.0 | 1:1 |
| 57.3° | 0.5 | 炮塔转 2 倍 |
| 14.3° | 2.0 | 炮塔转一半 |

`cmd = relNeed / K`。

**不要靠猜**：同一个蓝图，力驱动和关节驱动的传动比可以差一倍。

## 3. 三种控制器形态

### 3.1 开环（推荐）

```lua
yaw_target = relNeed / K
```

- 无反馈，不可能震荡
- 车体移动时需要重新计算（`relNeed` 已含车体，所以其实自动补偿）
- 前提：K 与零点准确

### 3.2 增量跟随（车体移动大时）

```lua
cmdHold = cmdHold + wrapPi(relNeed - relPrev) / K
```

`wrapPi` 只取增量的主值，避免 ±π 处跳 2π（否则车体会“转半圈、炮塔转一圈”）。

### 3.3 带死区的积分（仅当机械有回差时）

```lua
if math.abs(err) > TOL then
    cmd = cmd + clamp(err * KI, -STEP, STEP)
end
```

`TOL` 必须大于回差，否则形成极限环（持续小幅震荡）。

## 4. 实测过的故障谱

| 现象 | 根因 | 修法 |
|---|---|---|
| 炮塔自转 | 正反馈（误差符号反） | 翻 `K` 或翻基准符号 |
| 转半圈炮塔转一圈 | `wrapPi` 用在**指令**上 | 只对**增量**用 `wrapPi` |
| 小幅抽搐 | 死区小于测量噪声 | 加大 `TOL`，减小 `STEP` |
| 顶在 ±3.10 不动 | 指令饱和 | 检查 `K` 与零点，往往是把弧度当度 |
| 车体一动就偏 | 用世界角做基准 | 改为相对角 |

## 5. 底盘稳定性

炮塔快速旋转会给未锁定底盘反作用力矩，可能翻车。措施：

1. **限速**：`min(|Δcmd|, 0.02)` 每 tick，让步进变缓
2. **软化启动**：前 20 tick 用 30% 速度
3. **只在低速/静止时大幅转向**：检测车体速度
4. **机械**：底盘加重、加宽轮距、降低炮塔重心

```lua
local d = wrapPi(relNeed - relPrev) / K
d = clamp(d, -0.03, 0.03)          -- 限速
cmdHold = cmdHold + d
```
